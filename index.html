    Sync across devices

    Store your collection in a free JSONBin.io bin so it appears on every device. Use the same Master Key and Bin ID everywhere.

    1. Create a free account at jsonbin.io.
    2. Open API Keys and copy your Master Key.
    3. Paste the key below and press Connect — a bin is created automatically and its Bin ID is shown. Enter that same Bin ID (and key) on your other devices.

    Your Master Key is stored only in this browser and sent directly to JSONBin. Anyone with the key and Bin ID can read and edit the data, so keep them private and don't store anything sensitive.
